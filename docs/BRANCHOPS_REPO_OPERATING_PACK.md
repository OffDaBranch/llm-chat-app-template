# BranchOps Repo Operating Pack

This document defines the required Codex operating rules for this repository.

## Purpose
Make every Codex job traceable, reviewable, and connected to BranchOps source-of-truth systems.

## Required Completion Protocol
Every task must end with: Objective, Classification, Primary Agency, Departments / Roles Involved, Work Completed, Files Changed, Validation Performed, Risks / Compliance Notes, Source-of-Truth Updates Needed, Executive Review Board Decision, Handoff, and Next Executable Codex Prompt.

## Department Roster

Corporate Governance: Corporate Governance Lead, Legal Documentation Lead, Compliance Lead, Entity Separation Lead, Trust / Succession Lead.
Finance / Treasury: Treasury Lead, Intercompany Billing Lead, Accounting Systems Lead, Revenue Operations Lead, Tax Coordination Lead.
IP / Brand / Licensing: IP Ownership Lead, Licensing Director, Brand Systems Lead, Contract Packaging Lead, Digital Asset Lead.
Product / Software Engineering: Product Manager, Platform Architect, Backend Engineer, Frontend Engineer, DevOps / CI Lead, Technical Writer.
AI Platform: AI Systems Architect, Cloudflare Infrastructure Lead, Data / Memory Lead, API Security Lead, SaaS Monetization Lead.
Game Studio: Game Director, Gameplay Engineer, UI/UX Lead, Asset Pipeline Lead, Digital Wearables Lead, Game Economy Lead, QA Lead.
Website / Growth / Intake: Website Product Lead, Funnel / Conversion Lead, SEO / Content Lead, Data Capture Lead, Licensing Pipeline Lead, Privacy Lead.
Data / CRM / Source-of-Truth: Airtable Systems Lead, Notion Systems Lead, GitHub Records Lead, Data Quality Lead, Reporting Lead.
Security / Risk / Compliance: Security Lead, Privacy Lead, Deployment Risk Lead, Regulatory Risk Lead, Audit Readiness Lead.
QA / Release: QA Lead, Release Manager, Regression Tester, Review Lead, Validation Log Owner.
Operations / PMO: Program Manager, Build Queue Manager, SOP Manager, Handoff Coordinator, Dependency Manager.

## Decision Logic
Use exactly one: APPROVE, REVISE, BLOCK, or ESCALATE.

## Source-of-Truth Rules
Every task must state whether updates are needed in Airtable, Notion, GitHub, Cloudflare, Stripe, Mailchimp, or other connected systems.

## Handoff Template
- Task completed:
- Agency responsible:
- Departments involved:
- Files changed:
- Asset created or improved:
- Validation performed:
- Risks found:
- Source-of-truth updates:
- Founder approval needed:
- Next executable prompt:

## Standard Codex Prompt
Review this repository under the BranchOps Codex Agency Operating System. Classify the task, route it through the correct departments, complete the work, validate it, identify risks, produce a source-of-truth update list, make an Executive Review Board decision, create a handoff, and end with the next executable Codex prompt.
